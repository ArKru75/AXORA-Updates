# Посібники AXORA / AXORA user guides

Прості ілюстровані інструкції для **AXORA Calibrator 1.1.10**.
Редакція від **05.11.2026**, по **13 сторінок** українською та англійською.
Підключення, калібрування всіх 12 рухів, перевірки, особисті налаштування,
резервна копія, підсвічування, оновлення та швидка допомога.
У PDF є закладки розділів і переходи з обкладинки.

## Посилання для NFC

Чинна адреса українського посібника збережена. Перезаписувати наявні мітки не потрібно.
Для нової мітки додайте запис типу URL:

- [Український PDF](https://github.com/ArKru75/AXORA-Updates/blob/main/docs/AXORA-User-Guide-UA.pdf)
- [English PDF](https://github.com/ArKru75/AXORA-Updates/blob/main/docs/AXORA-User-Guide-EN.pdf)

Адреси публічні, без облікового запису або токена GitHub, і не містять номера версії.
Майбутні редакції публікуються за тими самими шляхами.
Контрольні суми наведено у [SHA256SUMS.txt](../SHA256SUMS.txt).

Choose your language above. Each 13-page guide covers Calibrator 1.1.10 with
