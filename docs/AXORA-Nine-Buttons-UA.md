# AXORA 2.1.17 — дев’ять кнопок

Плата: **Pro Micro / ATmega32U4, 5 В / 16 МГц**. Основа — прошивка 2.1.16
з виправленими затримками USB Serial. Для переназначення кнопок використовуйте калібратор 1.1.17 і прошивку 2.1.18.

## Підключення

Кожна нормально розімкнена кнопка підключається **між указаним піном і GND**.
Використовується внутрішня підтяжка INPUT_PULLUP; натискання — LOW.

| № AXORA | Пін на Pro Micro | Типове призначення 3DxWare | HID usage / біт | Report03 mask |
|---:|---|---|---|---|
|1|D2|1 / V3DK_1|13 /12|0x00001000|
|2|D3|2 / V3DK_2|14 /13|0x00002000|
|3|D7|3 / V3DK_3|15 /14|0x00004000|
|4|RX / D0|FIT / V3DK_FIT|2 /1|0x00000002|
|5|TX / D1|Rotation Lock / V3DK_ROTATE|27 /26|0x04000000|
|6|D10|Roll+ / V3DK_ROLL_CW|9 /8|0x00000100|
|7|D14 / MISO|TopView / V3DK_TOP|3 /2|0x00000004|
|8|D15 / SCK|RightView / V3DK_RIGHT|5 /4|0x00000010|
|9|D16 / MOSI|FrontView / V3DK_FRONT|6 /5|0x00000020|

Коди підтверджені за встановленим файлом виробника:
`3Dconnexion/3DxWare/3DxWinCore/Cfg/Base.xml`, пристрій **256F:C631**,
`ButtonInfo/Event/ReportID=03`. Для Roll+ у драйвері зазначено
`STR_RollPlus` / `V3DK_ROLL_CW`; для Rotation Lock — `V3DK_ROTATE`.
Профіль програми або персональні призначення 3DxWare можуть змінювати
дію, прив’язану до відповідної кнопки. Прошивка передає саме HID-коди.
Rotation Lock обробляє драйвер: це не одновісне блокування у прошивці.

RX/TX тут працюють як звичайні цифрові входи. USB Serial калібратора
використовує вбудований USB ATmega32U4 й не займає RX/D0 та TX/D1.
SPI-піни D14–D16 також використовуються як звичайні входи.
При програмуванні через зовнішній ISP кнопки на SPI потрібно відпускати.

Датчики залишаються на **A1, A0, A3, A2, A7, A6, A9, A8**, RGB — **D5**.
Враховано фізичні псевдоніми A6=D4, A7=D6, A8=D8, A9=D9.
Зайняті всі 18 штатно виведених сигнальних GPIO Pro Micro.

## Поведінка

- У CAD усі 9 кнопок передають незалежні натискання й відпускання.
  Одночасне натискання кількох кнопок не повинно стирати інші утримувані біти.
- Комбінації режимів/швидкості/центру залишаються на перших 3 кнопках.
  Додаткові 6 не стають частиною сервісної комбінації.
- У Slicer перші 3 зберігають попередні клавіатурні функції;
  додаткові 6 не надсилають CAD-команди та не створюють клавіатурних замін.
- Під час калібрування, імпорту, паузи HID або помилки CAD-кнопки не передаються.
  Утримувані додаткові кнопки не відтворюють старе натискання після паузи.
- Будь-яка з 9 кнопок блокує вимірювання центру/підтвердження стартової стабільності,
  тому після підключення USB відпустіть усі кнопки й рукоятку.

## Сумісність і перевірка

У калібраторі **1.1.17** з прошивкою **2.1.18** виберіть модель AXORA або
AXORA Pro та відкрийте **Експерт → Кнопки**. Виберіть HID-призначення для
кожної фізичної кнопки у стовпці **Призначення**, натисніть
**Зберегти призначення**, потім увімкніть CAD. У режимі AXORA Pro перевірка охоплює
всі дев’ять фізичних кнопок із призупиненим CAD.

Кожне HID-призначення доступне лише для однієї кнопки. Якщо пристрій уже
містить дублікати, виберіть вільні призначення перед збереженням.

Перед оновленням збережіть резервну копію калібрування. Після встановлення
перевірте кожну кнопку окремо та призначену дію в 3DxWare.
