# Встановлення та перепрошивання Pro Micro без ручного RESET

У калібраторі 1.1.10 цей режим потребує [сервісного мастер-пароля](AXORA-Service-Mode-UA.md).

Калібратор **1.1.9**, прошивка **2.1.15**, плата **Pro Micro / ATmega32U4,
5 В / 16 МГц**, підключення AXORA HW1, завантажувач **Caterina / AVR109**.

У розділі **Прошивка → Встановлення / перепрошивання плати** можна записати
AXORA на нову плату, замінити сторонній скетч або повторно записати ту саму
версію AXORA. Попередня відповідь AXORA HELLO не потрібна. Підтримуються
звичайні Arduino-скетчі та сторонні USB VID/PID; назва поточної прошивки
не є умовою для початку встановлення.

## Порядок

1. Якщо калібратор уже підключений до AXORA, натисніть **Відключити**
   у верхній панелі. USB-кабель залиште підключеним.
2. Відкрийте **Прошивка** та натисніть **Перевірити GitHub**.
   Дочекайтеся перевірки HEX і SHA-256.
3. У блоці **Встановлення / перепрошивання плати** натисніть
   **Оновити USB-порти** й виберіть порт своєї Pro Micro.
4. Підтвердьте **Pro Micro / ATmega32U4, 5 В / 16 МГц, Caterina**.
   Поточний скетч буде замінений без його резервної копії.
5. Натисніть **Прошити плату автоматично**. Калібратор сам відкриє
   вибраний порт на 1200 бод і переведе плату в завантажувач.
   Натискати RESET, замикати RESET/GND або ловити порт вручну не потрібно.
6. Дочекайтеся підтвердження версії AXORA. Для нової плати виконайте
   **повне навчання**. Якщо після перепрошивання доступна збережена матриця,
   перевірте центр, осі та кнопки. HID залишається призупиненим.

AVRDUDE береться з установленого пакета **Arduino AVR Boards**.
Інструмент перевіряє сигнатуру ATmega32U4 і Flash читанням. Перед записом
калібратор перевіряє HEX/SHA-256, а після нього — версію AXORA, HW1,
протокол і читання калібрування/налаштувань. Зміна номера COM допускається
лише в межах вибраного фізичного USB-з'єднання.

## Апаратна межа

Автоматичний USB-перезапуск на 1200 бод виконує **поточний скетч**, а не
незалежний USB-UART контролер. Тому перезапис через один USB-кабель без
ручного RESET можливий, якщо скетч зберіг робочий USB COM і підтримку
перезапуску, а Caterina не пошкоджена.

Якщо скетч вимкнув CDC/COM, не обробляє команду перезапуску, завис так,
що USB не працює, або чип не має завантажувача, довільно запустити Caterina
з калібратора неможливо. Для такого стану потрібен **ISP-програматор**
з апаратним керуванням RESET. Це не усувається зміною перевірки VID/PID.
Калібратор повідомляє про це червоним і не намагається писати інший COM-порт.

Механізм 1200-baud reset: [вихідний код ядра Arduino](https://github.com/arduino/ArduinoCore-avr/blob/master/cores/arduino/CDC.cpp).

## Збережені дані

Цей прямий режим не створює копії попереднього скетча або калібрування
до запису. Він не передає команди запису EEPROM, fuse, завантажувача
або повного стирання чипа. Сумісна збережена матриця AXORA читається
після встановлення; її наявність перевіряється окремо від успіху запису Flash.

Для планового оновлення робочої AXORA рекомендована звичайна кнопка
**Оновити прошивку**: вона додатково створює резервну копію та звіряє
калібрування до/після запису. Повторний запис тієї самої версії виконується
через явний режим **Встановлення / перепрошивання**.

Журнал `avrdude.log` та перевірений `firmware.hex` лежать у
`%LOCALAPPDATA%\AXORA\Calibrator\Backups\Install_…`.
Відомі Pro Micro 3,3 В / 8 МГц та поширені USB-UART адаптери не пропонуються.
USB VID/PID не доводить фактичну модель або частоту плати: перевірте маркування.

Прошивка HEX для ATmega32U4 не підходить для ESP32 або nRF52840.
Підтримку таких плат потрібно реалізовувати окремо.

Автоматичний сценарій перевірено тестами з імітацією USB-портів, плати й
AVRDUDE; фізичну Pro Micro під час цієї розробки не прошивали.
