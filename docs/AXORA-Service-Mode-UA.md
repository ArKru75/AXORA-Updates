# Сервісний доступ — калібратор 1.1.10

Режим **Прошивка → Встановлення / перепрошивання плати** доступний
після введення мастер-пароля, налаштованого власником AXORA.
Він охоплює нові Pro Micro, заміну стороннього скетча та повторний запис AXORA.

1. Відкрийте **Прошивка** й натисніть **Перевірити GitHub**.
2. У сервісному блоці введіть мастер-пароль і натисніть **Розблокувати**
   або Enter. Символи пароля приховані.
3. Оновіть USB-порти, виберіть свою Pro Micro 5 В / 16 МГц із Caterina
   та підтвердьте тип плати.
4. Натисніть **Прошити плату автоматично**. Далі діє
   [автоматичний сценарій встановлення](AXORA-Board-Installation-UA.md).

Розблокування дозволяє **один запис**. Доступ блокується знову на початку
операції, зокрема після її невдалого завершення. Для наступного запису
пароль потрібно ввести повторно. Нове вікно калібратора починає роботу
із заблокованим сервісним режимом.

**Скасувати** або Escape очищує введений пароль. Після розблокування кнопка
**Заблокувати** закриває доступ і скидає вибір плати. Неправильний пароль
показує червоне повідомлення в цьому ж блоці та не дозволяє сканування
USB-портів або запуск запису. Запит пароля не викликає перезапуск плати.

Пароль не зберігається в налаштуваннях, резервних копіях або журналах.
У виконуваному файлі є лише перевірочне значення PBKDF2 із сіллю.
Мастер-пароль керує доступом до сервісного розділу цієї програми.

Звичайна кнопка **Оновити прошивку** для підключеної AXORA й перевірка
GitHub доступні **без мастер-пароля**. Резервне копіювання та перевірка
збереження калібрування при звичайному оновленні залишаються обов'язковими.

Прошивка пристрою залишається **2.1.15**. Умови автоматичного USB-перезапуску
й потреба в ISP для плат без робочого CDC/Caterina залишаються чинними.
