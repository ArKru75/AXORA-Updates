# AXORA 2.9.3 · AXORA AIR 2.7.0 — Bluetooth

Інструкції до поточних AXORA (4 кнопки) та AXORA Pro (15 кнопок), по 6 сторінок:
[Українською (PDF)](AXORA-User-Guide-UK.pdf) · [English (PDF)](AXORA-User-Guide-EN.pdf).
Підключення, калібрування, CAD, миша, AIR, телефон, оновлення та допомога.

Оновіть **лише AXORA / AXORA Pro до 2.9.3** через вебкалібратор, по USB
або через AXORA AIR. **AIR 2.7.0 не потребує оновлення**.
Калібрування, параметри, призначення кнопок і пара зберігаються.
Після встановлення перезавантажте сторінку браузера. BOOT/RESET не потрібні.

| Прилад | BIN для вебоновлення |
|---|---|
| AXORA / AXORA Pro | [axora-max-tx-2.9.3.bin](axora-max-tx-2.9.3.bin) |
| AXORA AIR — без змін | [axora-esp32-wireless-rx-2.7.0.bin](axora-esp32-wireless-rx-2.7.0.bin) |

[Обидві актуальні прошивки ZIP](AXORA-Bluetooth-2.9.3.zip).
Перед вибором BIN розпакуйте архів. Файли з папки `factory` призначені
для першого запису кабелем, а не для вебоновлення.

## Зміни

- У списку незбережених змін можна відкрити потрібний розділ або скасувати
  тільки його правки. Інші чернетки зберігаються.
- У миші основні швидкості доступні одразу; зони спокою, поріг фіксації
  й напрямки розташовані в «Точному налаштуванні».
- «Відпустити всі кнопки» знімає фіксації миші, зберігаючи режим і параметри.
- Натискання числа біля повзунка відкриває точне введення та початкове
  значення цього параметра. «Готово» змінює чернетку; «Зберегти» пише в AXORA.
- У перевірці рухів використано зображення напрямків із налаштувань CAD.
- Узгоджено українські/англійські підказки та назви команд збереження.

Використовуйте оригінальні підписані файли AXORA. Старі непідписані BIN
не приймаються вебоновлювачем. Розмітка пам’яті та режими керування збережені.
Це експериментальний канал: автоматичні перевірки пройдено;
фізичні та тривалі випробування окремо позначаються у звіті.
