# AXORA Bluetooth 2.8.3 · AXORA AIR Bluetooth 2.6.2

## Установлення

Оновіть **AXORA / AXORA Pro до 2.8.3** через вебкалібратор: режим
**Експерт → Оновлення → Перевірити оновлення** або **Оновити з файлу**.
Доступне встановлення через USB або Bluetooth AXORA AIR, без BOOT/RESET.
Після встановлення перезавантажте сторінку браузера.
**AIR 2.6.2 повторно оновлювати не потрібно.**

| Пристрій | BIN для вебоновлення |
|---|---|
| AXORA / AXORA Pro | [axora-max-tx-2.8.3.bin](axora-max-tx-2.8.3.bin) |
| AXORA AIR — без змін | [axora-esp32-wireless-rx-2.6.2.bin](axora-esp32-wireless-rx-2.6.2.bin) |

[Обидві актуальні прошивки ZIP](AXORA-Bluetooth-2.8.3.zip). Перед вибором BIN розпакуйте архів.

## Скидання й одна фіксація

**Підніміть ручку вгору, щоб відпустити всі кнопки миші.** Прилад
залишається в режимі миші. Підняття працює також під час повороту;
незавершені кліки й жести скасовуються. Поверніть ручку в нейтральне
положення перед наступним жестом. Повернення саме по собі не натискає кнопку.
Дрібні коливання й короткі випадкові стрибки не скидають фіксацію.

**Одночасно може бути зафіксована лише одна кнопка.** Нова фіксація лівої,
правої або середньої відпускає попередню. Клік іншою кнопкою також спочатку
знімає стару фіксацію, щоб не утворювати одночасних натискань. У тестовій
панелі видно поточну кнопку або напис, що кнопки відпущені.

## Жести

| Рух ручки | Дія за початкового напрямку |
|---|---|
| Нахил | Переміщення курсора |
| Зміщення паралельно основі | Прокручування |
| Поворот до половини ходу за годинниковою, потім у центр | Лівий клік |
| Поворот до половини ходу проти годинникової, потім у центр | Правий клік |
| Максимальний поворот із утриманням близько 0,35 с | Фіксація відповідної кнопки |
| Повторний поворот до половини ходу в той самий бік | Відпускання цієї кнопки |
| Окреме глибоке натискання вниз близько 0,2 с | Фіксація середньої кнопки — натискання на колесо |
| Повторне глибоке натискання вниз | Відпускання середньої кнопки |
| Підняття вгору | Відпускання всіх кнопок |

**Пауза** у шапці також відпускає кнопки. Підняття відпускає їх без
переходу в Паузу. Перемикач **Поворот навколо вертикалі → Навпаки** міняє
ліву та праву дії місцями; стан перемикача збережений. Початкове зусилля
фіксації 100%, з можливістю власного налаштування. Глибоке натискання
вниз захищене від супутнього руху під час повороту, як у 2.8.2.

Усі фізичні кнопки працюють через 3DxWare. Довге утримання фізичної 2 на
AXORA / верхньої 4 на Pro з відпусканням перемикає CAD / Миша. Параметри,
калібрування, зусилля, інверсії, призначення, яскравість і Bluetooth-пара
зберігаються. Формати записів, радіо HID, STATE, MOUSECFG, розмітка OTA та
імена проєктів не змінені. Назва `axora-max-tx` потрібна для сумісності
попереднього вебоновлювача.

## Перевірки

[Повні тести й обидві збірки](https://github.com/ArKru75/AXORA/actions/runs/46021189551): C++ з UBSan, Bluetooth/OTA та шість
браузерних наборів. Перевірено скидання кожної кнопки підняттям, межу
підтвердження, шум, незавершений клік, утримання повороту після підняття,
повернення без нового натискання, новий жест після повернення, заміну між
трьома фіксаціями, відсутність одночасних натискань протягом 12000
контрольних кадрів і звіти через реальний шлях формування HID.
Оновлені підказки перевірені українською й англійською, на ПК та телефоні.
Розмір, контрольні суми, оригінальні OTA-розділи й відповідність заводського
та OTA-образів перевірені. Фізичний пристрій не перепрошивався.
