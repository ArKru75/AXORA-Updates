# AXORA Bluetooth 2.6.1 · AXORA AIR Bluetooth 2.5.2

На сторінці AXORA AIR прибрано верхню кнопку AXORA після прапорців мови. Показники **Пара збережена**, **AXORA відповідає**, **Калібратор доступний** тепер мають зелену **✓** або червоний **✕**, без написів «Так» / «Ні». Для читачів екрана збережено відповідні українські й англійські назви.

Основна кнопка **Відкрити AXORA** під показниками залишається та працює лише коли калібратор доступний. Якщо сторінку `/wireless` відкрито на AXORA напряму через USB, ця кнопка також відкриває її калібратор. Панель логотипа й мови вирівняна на комп’ютері, збережено компактний вигляд на телефоні.

## Установлення

Для нового вигляду сторінки приймача достатньо оновити **AXORA AIR до 2.5.2** на комп’ютері: **http://axora.local/wireless → Перевірити оновлення** або **Оновлення з файлу**.

| Пристрій | Файл для вебоновлення |
|---|---|
| AXORA AIR | [axora-esp32-wireless-rx-2.5.2.bin](axora-esp32-wireless-rx-2.5.2.bin) |
| AXORA / AXORA Pro | [axora-max-tx-2.6.1.bin](axora-max-tx-2.6.1.bin) |

AXORA 2.6.1 містить ті самі зміни для власної сторінки бездротового з’єднання при прямому USB-підключенні. Оновіть її в калібраторі → **Оновлення** напряму через USB або через Bluetooth AIR.

[Обидва файли ZIP](AXORA-Bluetooth-2.6.1.zip). Перед вибором BIN розпакуйте архів. BOOT/RESET не потрібні. Після встановлення оновіть сторінку браузера. Наявну Bluetooth-пару створювати повторно не потрібно.

Калібрування, центри, яскравість, профілі, кнопки та підключення не змінюються. У калібраторі дві моделі: **AXORA — 4 кнопки Escape/Fit/1/2 на GPIO10–13**, **AXORA Pro — колишня Max з 15 кнопками PCF8575**. В обох — сім світлодіодів, RGB на GPIO21. Стара дев’ятикнопкова Pro вилучена з 2.6.0. [Розпіновка та перехід на дві моделі](https://github.com/ArKru75/AXORA/blob/codex/axora-bluetooth/firmware/esp32/CHANGES_2_6_0.md).

Перший перехід з ESP-NOW потребує Bluetooth-прошивок на обох пристроях та створення нової пари. Оновлення в межах Bluetooth зберігає пару. Ім’я файла `axora-max-tx` навмисно лишається сумісним із попереднім вебоновлювачем.
