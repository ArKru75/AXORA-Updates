# AXORA ESP32-S3 Wireless · 2.1.14

Два ESP32-S3 Super Mini з 4 МБ flash. Передавач підключений до датчиків, кнопок і підсвічування AXORA. Приймач підключений до ПК через USB-C та працює як пристрій 3Dconnexion і USB-мережевий адаптер для вебкалібратора. Плати обмінюються даними через ESP-NOW на каналі 6, без підключення до роутера.

## Прошивки

Калібратор і Axora Air мають спільне оформлення для телефона та ПК. Пункт **Wi-Fi для телефона** розташований одразу над **Axora Air**. У **Налаштуваннях** об’ємні стрілки показують напрямки зміщення й обертання рукоятки. Мову можна перемикати як у калібраторі, так і в Axora Air.

У вебкалібраторі виберіть **AXORA** або **AXORA Pro** в меню **Модель**. Калібратор показує зображення вибраної моделі з однаковими стрілками для всіх 12 рухів. Через Axora Air ілюстрації для обох моделей доступні після оновлення обох плат до 2.1.14.

### Доступ із телефона

Передавач 2.1.14 створює власну захищену мережу Wi-Fi **AXORA-XXXXXX**. Відкрийте вебкалібратор через USB або Axora Air і відкрийте **Wi-Fi для телефона** в основному меню. У цьому розділі можна дізнатися назву мережі й змінити її пароль. Після зміни знову підключіть телефон до цієї мережі з новим паролем.

На телефоні або ноутбуці приєднайтеся до Wi-Fi **AXORA-XXXXXX** і відкрийте **http://axora.local/** або **http://192.168.4.1/**. Для цього достатньо живлення TX і браузера. У режимі Axora Air USB-приймач і далі передає рухи та кнопки одночасно з доступом до вебкалібратора по Wi-Fi. Щоб змінювати пароль через Axora Air, оновіть TX і RX до 2.1.14. Установлення прошивок і спарювання виконуйте через **http://192.168.77.1/**.

У 2.1.8 передавач можна оновити по ESP-NOW через USB-приймач. У шапці **Axora Air** кнопка з логотипом **AXORA** повертає до калібратора, коли RX має радіозв’язок із TX.

Для першого переходу на радіооновлення окремо встановіть 2.1.8 на TX і RX через USB. Для наступних оновлень TX підключіть RX до ПК, подайте живлення на передавач і відкрийте **http://192.168.77.1/**. У розділі вебкалібратора **Оновлення** можна встановити прошивку TX з GitHub або з файла `tx-compat`. Передавач перезапускається після перевірки образу. При обриві до завершення запису TX продовжує працювати з попереднім образом. Розділ **Axora Air → Оновлення приймача** оновлює RX.

| Роль | Перший запис за адресою 0x0 | Оновлення відповідної ролі |
| --- | --- | --- |
| Передавач | [Запис через ESP-IDF](https://github.com/ArKru75/AXORA/tree/axora-esp32-wireless/firmware/esp32) | [Сумісний файл TX](axora-esp32-wireless-tx-compat-2.1.14.bin) |
| USB-приймач | [Заводський образ](axora-esp32-wireless-rx-2.1.14-factory.bin) | [Файл оновлення](axora-esp32-wireless-rx-2.1.14.bin) |

[Архів RX](AXORA-ESP32-S3-Wireless-rx-2.1.14.zip) і [контрольні суми SHA‑256](SHA256SUMS.txt).

Для радіозв’язку обидві плати мають працювати на 2.1.4 або новішій версії. Оновлюйте кожну плату напряму через USB. Якщо на RX ще встановлено 2.1.3 і зв’язку з TX немає, завантажте файл RX із таблиці та відкрийте **Бездротовий зв’язок → Оновлення з файла**. Починаючи з 2.1.4 приймач може перевіряти GitHub і встановлювати наступні версії зі своєї сторінки **Бездротовий зв’язок → Оновлення приймача** навіть із вимкненим передавачем. Збережена пара й калібрування доступні після оновлення.

### Перехід з дротової 2.0.9 без BOOT і RESET

Завантажте [сумісний OTA-образ TX 2.1.14](axora-esp32-wireless-tx-compat-2.1.14.bin). У вебкалібраторі 2.0.9 відкрийте **Експерт → Оновлення → Оновити з файлу** й виберіть цей файл. Після запису плата автоматично перезапуститься. Образ поміщається в чинні слоти по 1 МіБ і використовує окремий канал подальших вебоновлень.

### Перший запис прошивки

Для чистої плати TX або переходу зі старої стандартної розкладки використайте [збірку й повний запис через ESP-IDF](https://github.com/ArKru75/AXORA/tree/axora-esp32-wireless/firmware/esp32). Перед зміною розкладки збережіть резервну копію калібрування. Після запису відновіть її через вебкалібратор.

Для першого запису RX під’єднайте приймач USB-кабелем і виберіть його COM-порт. За потреби затисніть BOOT, коротко натисніть RESET і відпустіть BOOT.

~~~powershell
python -m esptool --chip esp32s3 --port COM7 write_flash 0x0 axora-esp32-wireless-rx-2.1.14-factory.bin
~~~

## Спарювання через вебсторінку приймача

1. Підключіть приймач до ПК, а передавач живіть від зарядного пристрою або павербанка.
2. Через приймач відкрийте **http://axora.local/**. Сторінка **Бездротовий зв’язок** покаже AXORA поблизу. Виберіть пристрій і натисніть **З’єднати**.
3. Звірте вісім спалахів підсвічування AXORA з послідовністю на сторінці. Якщо кольори збігаються, підтвердьте. Після встановлення радіозв’язку натисніть кнопку з логотипом **AXORA**, щоб повернутися в калібратор.

Плати самі узгоджують ключ, зберігають пару й надалі з’єднуються автоматично. Пари з попередніх версій зберігаються. Щоб замінити одну з плат, відкрийте **http://axora.local/wireless** і виберіть **Забути пару**. Якщо друга плата була вимкнена або пару налаштовували вручну в попередній версії, очистіть пару й на другій платі через її USB-сторінку. Підключайте до ПК одну плату за раз, бо обидві використовують однакову USB-адресу.

## Робота

- **Передавач напряму.** Підключіть TX кабелем передачі даних до ПК. Він працює як пристрій 3Dconnexion і відкриває власний вебкалібратор за адресою `http://axora.local/`. Приймач для цього режиму не потрібний.
- **Через приймач.** Підключіть RX до ПК, а TX живіть окремо. Вебкалібратор відкривається за адресою `http://axora.local/` через RX. Приймач отримує інтерфейс із TX по ESP-NOW і передає браузеру. Команди, показники та підтвердження йдуть тим самим шляхом. Інтерфейс, калібрування й налаштування зберігаються на TX.
- **Без зв’язку з TX.** Приймач відкриває власну сторінку **Бездротовий зв’язок** для спарювання й оновлення RX з GitHub або з файла. Після відновлення зв’язку стає доступною кнопка **AXORA**.
- При розпізнаванні TX по USB прямий USB має пріоритет для рухів і кнопок. Через RX і далі доступний вебкалібратор. Після перемикання відпустіть рукоятку, щоб відновити передачу руху.
- Приймач передає HID для CAD та допоміжні звіти миші й клавіатури по USB. Якщо радіокадри не надходять протягом 150 мс, приймач відпускає кнопки й обнуляє рух.
- Для прямого USB-оновлення TX підключіть передавач до ПК й відкрийте **http://192.168.77.1/**. Для оновлення RX підключіть приймач і відкрийте **http://192.168.77.1/wireless**.

## Підключення передавача

| Підключення | GPIO |
| --- | --- |
| Датчики S1–S8 | 1, 2, 4, 5, 6, 7, 8, 9 |
| Кнопки B1–B3 | 10, 11, 12 |
| Кнопки Pro B4–B9 | 13, 14, 15, 16, 17, 18 |
| DIN першого WS2812B | 21 |
| Нативний USB-C | 19 — D−, 20 — D+ |

Датчики та кнопки підключаються так само, як у дротовій AXORA ESP32. Аналогові входи працюють з рівнями 3,3 В. Зовнішні WS2812B живляться від 5 В і використовують узгодження рівнів для DIN. Для приймача додаткові підключення не потрібні.

## Збірка з ESP-IDF 5.5.2

У каталозі `firmware/esp32`:

~~~bash
idf.py -B build-tx-compat -D IDF_TARGET=esp32s3 -D AXORA_ROLE=tx -D SDKCONFIG=sdkconfig-tx-compat build
idf.py -B build-rx -D IDF_TARGET=esp32s3 -D AXORA_ROLE=rx -D SDKCONFIG=sdkconfig-rx build
~~~

Образ TX займає 949 600 байтів у слоті 1 МіБ. Образ RX займає 917 376 байтів у слоті 1 310 720 байтів. [Документація Espressif ESP-NOW](https://docs.espressif.com/projects/esp-idf/en/v5.5.2/esp32s3/api-reference/network/esp_now.html).
