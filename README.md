# AXORA 2.9.0 · AXORA AIR 2.7.0 — Bluetooth

Оновлений інтерфейс калібратора та AXORA AIR, компактні сторінки телефона,
огляд стану, довідка без інтернету, звіт для підтримки й підписані оновлення.
Це експериментальний канал: автоматичні перевірки пройдені, апаратні та
тривалі випробування ще не позначені завершеними.

## Оновлення через вебсторінку

1. Спочатку встановіть **AXORA AIR 2.7.0** на її сторінці оновлення.
2. Встановіть **AXORA / AXORA Pro 2.9.0** у калібраторі через USB або AIR.
3. Залиште живлення ввімкненим до повідомлення про завершення перевірки запуску.
4. Перезавантажте сторінку браузера. Калібрування, налаштування та пара зберігаються.

| Прилад | BIN для вебоновлення |
|---|---|
| AXORA / AXORA Pro | [axora-max-tx-2.9.0.bin](axora-max-tx-2.9.0.bin) |
| AXORA AIR | [axora-esp32-wireless-rx-2.7.0.bin](axora-esp32-wireless-rx-2.7.0.bin) |

[Обидва файли ZIP](AXORA-Bluetooth-2.9.0.zip). Перед вибором BIN розпакуйте архів.
BOOT/RESET для вебоновлення не потрібні. Файли з папки `factory` призначені
для першого запису кабелем, а не для вибору у вебоновлювачі.

## Підписані файли

Чинні попередні прошивки можуть установити ці BIN через «Оновити з файлу».
Після встановлення наступні вебоновлення мають містити дійсний підпис AXORA.
Старі непідписані BIN не приймаються для ручного повернення. Докладні межі
відновлення на старих і нових завантажувачах описано в змінах до версії.
Підпис не закриває завантаження файлів і не потребує коду активації.
