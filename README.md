# AXORA Bluetooth 2.5.3 · AXORA AIR Bluetooth 2.5.1

Оптимізовано оновлення AXORA через Bluetooth. Під час передавання AIR запитує швидкісний режим; після завершення, помилки або повторення запиту через тайм-аут повертається до звичайного. Відмова у швидкісному режимі не розриває робоче з’єднання.

AXORA об’єднує дрібні блоки перед записом у пам’ять і припиняє зайві пакети руху під час установлення. Перевірка цілісності, захист від неповного запису, USB, калібрування, призначення кнопок і збережена Bluetooth-пара залишаються.

## Як оновити Bluetooth-пристрої

1. Спочатку оновіть **AXORA AIR до 2.5.1**: на комп’ютері відкрийте `http://axora.local/wireless` → **Оновлення** або **Оновлення з файлу**.
2. Потім оновіть **AXORA до 2.5.3** у калібраторі → **Оновлення**. Можна через AIR або прямим USB-кабелем.
3. Після оновлення повторно відкрийте сторінку калібратора на комп’ютері чи телефоні.

Повторне спарювання для вже наявної Bluetooth-пари не потрібне. Нові ролі також працюють із попередніми Bluetooth-прошивками, тому їх можна оновлювати послідовно. Повний ефект оптимізації буде після встановлення обох нових версій; буферизований запис працює для подальших оновлень уже оновленого пристрою.

| Пристрій | Файл для «Оновити з файлу» |
|---|---|
| AXORA / Pro / Max | [axora-max-tx-2.5.3.bin](axora-max-tx-2.5.3.bin) |
| AXORA AIR | [axora-esp32-wireless-rx-2.5.1.bin](axora-esp32-wireless-rx-2.5.1.bin) |

[Обидва файли одним архівом](AXORA-Bluetooth-2.5.3.zip). Перед вибором BIN розпакуйте архів. BOOT/RESET не потрібні; файли призначені для наявного вебоновлення.

## Що перевірено

[Повна перевірка та збірка GitHub Actions](https://github.com/ArKru75/AXORA/actions/runs/45858751990) на локальному runner: нативні тести, шифрування, п’ять браузерних наборів і обидві прошивки. Додатковий тест виконує справжній код запису з реальною SHA-256 та імітацією пам’яті: повний і неповний запис, відмова пам’яті, помилкова контрольна сума, скасування та безпечна активація.

У тесті на 997808 байтах кількість викликів запису зменшилася з 1002 до 244. Це скорочення операцій, а не виміряне прискорення на реальній парі. Залишено ті самі межі пакетів, розмітку пам’яті та захист даних. Реальна швидкість залежить від зв’язку; вимірювання на фізичних пристроях у цьому випуску не виконувалося.

Усі виправлення мобільних незбережених змін із 2.5.2 та збереження центрів із 2.5.1 включені.

## Перший перехід з ESP-NOW

Установіть відповідні Bluetooth BIN на обидва пристрої через пряме USB-підключення. Потім створіть Bluetooth-пару на сторінці AIR, вибравши AXORA й підтвердивши порядок кольорів. Додавати AXORA в Bluetooth-меню Windows чи macOS не потрібно. Пристрої з різними типами радіопрошивок не з’єднаються.

Пряме USB-підключення AXORA збережене. Калібратор зберігається в AXORA; AIR читає його через Bluetooth. Wi-Fi для телефона вмикається через 10 секунд без USB-з’єднання з комп’ютером та без зв’язку з AIR.
