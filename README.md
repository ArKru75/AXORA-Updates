# AXORA ESP32-S3 · 2.0.1

[Завантажити AXORA ESP32-S3 2.0.1](https://raw.githubusercontent.com/ArKru75/AXORA-Updates/axora-esp32/AXORA-ESP32-S3-2.0.1.zip) · [SHA-256](SHA256SUMS.txt)

Прошивка для **ESP32-S3 Super Mini** з нативним USB-C і від 4 МБ flash. Один USB-кабель передає HID для CAD та підключає вебкалібратор. Wi-Fi не використовується.

## Перший запис

Розпакуйте ZIP і запишіть файл **build/AXORA-ESP32-2.0.1-factory.bin** з адреси 0x0. За потреби затисніть BOOT, коротко натисніть RESET і відпустіть BOOT. Після запису натисніть RESET. Замініть COM7 номером порту плати.

~~~powershell
python -m esptool --chip esp32s3 --port COM7 write_flash 0x0 build/AXORA-ESP32-2.0.1-factory.bin
~~~

Для оновлення вже прошитої AXORA ESP32 через вебкалібратор виберіть **build/axora-esp32.bin**.

## Підключення

Орієнтуйтеся на маркування GPIO на своїй платі. На поширеній Super Mini контакти GPIO14–18 і GPIO21 розташовані знизу. Підключіть спільну землю для плати, датчиків, кнопок і світлодіодів.

| Підключення | GPIO |
| --- | --- |
| Датчики S1–S8, у тому самому порядку, що й на попередній AXORA | 1, 2, 4, 5, 6, 7, 8, 9 |
| Кнопки B1–B3 | 10, 11, 12 |
| Додаткові кнопки B4–B9 для Pro | 13, 14, 15, 16, 17, 18 |
| DIN першого зовнішнього WS2812B | 21 |
| Вбудований USB-C | 19 — D−, 20 — D+ |

- Кожна кнопка замикає свій GPIO на GND. Внутрішні підтягування ввімкнені.
- Аналогові входи ESP32-S3 працюють із рівнями 3,3 В. Якщо на старій платі датчики живляться від 5 В, перевірте вихідний діапазон і узгодьте кожен канал. Наприклад, для сигналу 0–5 В подільник 10 кОм від датчика до GPIO та 15 кОм від GPIO до GND дає 0–3,0 В. 100 нФ від входу до GND зменшує шум. Після монтажу виконайте повне калібрування.
- Зовнішні WS2812B живляться від 5 В. Для DIN використовуйте перетворювач рівня 3,3 → 5 В (наприклад, 74AHCT125) зі спільною землею. Підключіть 3 світлодіоди для AXORA або 7 для AXORA Pro.
- GPIO0 (BOOT), GPIO3, 45 і 46 залишені вільними. GPIO19/20 належать USB-C. Схема не використовує GPIO48, на якому деякі плати мають власний індикатор.

[Електричні характеристики ESP32-S3](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/schematic-checklist.html) · [Розташування контактів поширеної Super Mini](https://chiptron.eu/pinouts/esp32-s3-super-mini-pinout/)

## Пам’ять

Образ із вбудованим вебкалібратором займає **673 888 байтів**. У слоті розміром 1 МіБ залишається **374 688 байтів**. Розкладка для 4 МБ flash має початковий слот і два слоти оновлення.

## Вебкалібратор

У шапці є оригінальний логотип AXORA. Під час повного калібрування відображаються всі 12 ілюстрацій зі стрілками з Windows-калібратора.

Підключіть плату USB-кабелем передачі даних. Після появи мережевого адаптера відкрийте **http://axora.local/**. Якщо комп’ютер не розпізнає ім’я mDNS, відкрийте **http://192.168.77.1/**. AXORA видає адресу лише USB-адаптеру й не оголошує шлюз або DNS для доступу в інтернет. Нативний драйвер USB NCM документований для Windows 11. [Таблиця драйверів Microsoft](https://learn.microsoft.com/en-us/windows-hardware/drivers/usbcon/supported-usb-classes)

- **Звичайний** — повне калібрування на 12 положеннях і коригування центру, налаштування шести осей, яскравість та бігуча веселка, офіційне завантаження 3DxWare.
- **Експерт** — також перевірка рухів і кнопок, унікальні HID-призначення, центри датчиків, журнал, запис рухів та оновлення прошивки.
- У калібруванні можна зберегти та відновити резервну копію ESP32, яка включає матрицю, центри, налаштування осей, HID і підсвічування. Аналогові шкали відрізняються від ATmega32U4. Для ESP32 потрібне окреме калібрування.
- Для оновлення через вебінтерфейс виберіть **axora-esp32.bin** у розділі «Оновлення». Запис іде в інший слот, а після перевірки образу плата перезапускається. Завантажуйте інсталятор 3DxWare з офіційної сторінки в браузері та запускайте його у Windows.
- Для перевірки кнопок увімкніть відповідний тест. Фізичні комбінації перших трьох кнопок успадковані з AXORA 2.1.20.

## План бездротового режиму

У 2.0.1 вебкалібратор відкривається через USB-C. У майбутній бездротовій конфігурації приймач, підключений до ПК через USB, віддаватиме вебкалібратор за адресою http://axora.local/. Радіоканал між приймачем і AXORA має працювати в обидва боки. AXORA надсилатиме рухи, кнопки й стан, а приймач передаватиме команди калібрування та налаштувань і повертатиме браузеру підтвердження від AXORA.

Розпіновка 2.0.1 залишає всі вісім датчиків на ADC1 (GPIO1, 2, 4–9), якщо надалі ввімкнемо Wi-Fi. Прямий доступ через Wi-Fi з телефона або ПК без USB-приймача можна додати окремо. Оновлення прошивки передавача через радіоканал потребує окремої реалізації.
