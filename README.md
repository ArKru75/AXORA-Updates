# AXORA 2.9.6 · AXORA AIR 2.7.1 — Bluetooth

## Оновлення

1. Оновіть **AXORA AIR до 2.7.1** на її сторінці оновлення.
2. Оновіть **AXORA / AXORA Pro до 2.9.6** через калібратор по USB або AIR.
3. Перезавантажте сторінку браузера.

Калібрування, налаштування, кнопки та пара зберігаються. BOOT/RESET не потрібні.
Без AIR достатньо оновити лише AXORA.

| Прилад | BIN для вебоновлення |
|---|---|
| AXORA / AXORA Pro | [axora-max-tx-2.9.6.bin](axora-max-tx-2.9.6.bin) |
| AXORA AIR | [axora-esp32-wireless-rx-2.7.1.bin](axora-esp32-wireless-rx-2.7.1.bin) |

[Обидві прошивки ZIP](AXORA-Bluetooth-2.9.6.zip). Розпакуйте перед вибором BIN.
Файли з папки `factory` призначені для першого запису кабелем.

## Зміни

- У «Центрах датчиків» рядок червоний, коли поточне значення виходить за
  допуск ±35 від збереженого центру або за робочий діапазон датчика.
- Червоне позначення зникає при поверненні в норму. Незбережене редагування
  центру не змінює межі перевірки. Відпустіть рукоятку для перевірки центру.
- Виправлено блокування вбудованого фонового логотипа політикою безпеки
  сторінки в AXORA та AIR. Фон працює без інтернету по USB, Bluetooth і Wi-Fi.

[Інструкція українською (PDF)](AXORA-User-Guide-UK.pdf) · [English (PDF)](AXORA-User-Guide-EN.pdf).

Використовуйте оригінальні підписані BIN AXORA. Розмітка пам’яті та
режими керування збережені. Це експериментальний канал: автоматичні
перевірки пройдено; фізичне випробування пристроїв не виконувалося.
