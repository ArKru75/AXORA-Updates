# AXORA ESP32-S3 Wireless · 2.1.3

Два ESP32-S3 Super Mini з 4 МБ flash. Передавач підключений до датчиків, кнопок і підсвічування AXORA. Приймач підключений до ПК через USB-C та працює як пристрій 3Dconnexion і USB-мережевий адаптер для вебкалібратора. Плати обмінюються даними через ESP-NOW на каналі 6, без підключення до роутера.

## Прошивки

| Роль | Перший запис за адресою 0x0 | Оновлення відповідної ролі |
| --- | --- | --- |
| Передавач | [Заводський образ](axora-esp32-wireless-tx-2.1.3-factory.bin) | [Файл оновлення](axora-esp32-wireless-tx-2.1.3.bin) |
| USB-приймач | [Заводський образ](axora-esp32-wireless-rx-2.1.3-factory.bin) | [Файл оновлення](axora-esp32-wireless-rx-2.1.3.bin) |

Архіви та контрольні суми для завантаження: [TX](AXORA-ESP32-S3-Wireless-tx-2.1.3.zip), [RX](AXORA-ESP32-S3-Wireless-rx-2.1.3.zip), [SHA-256](SHA256SUMS.txt).

Для переходу з попередньої версії Wireless оновіть **спочатку TX, потім RX** через **Експерт → Оновлення**. Якщо RX уже встановлено, а TX ще недоступний, на сторінці **Бездротовий зв’язок** є **Оновлення з файла** для локального OTA-оновлення підключеної плати. Збережена пара й калібрування доступні після оновлення.

### Перехід з дротової 2.0.9 без BOOT і RESET

Завантажте [сумісний OTA-образ TX 2.1.3](axora-esp32-wireless-tx-compat-2.1.3.bin). У вебкалібраторі 2.0.9 відкрийте **Експерт → Оновлення → Оновити з файлу** й виберіть цей файл. Після запису плата автоматично перезапуститься. Образ займає 1 004 256 байтів, залишає чинні слоти по 1 МіБ і використовує окремий канал подальших вебоновлень.

### Перший запис заводського образу

Перед записом заводського образу поверх дротової прошивки збережіть резервну копію калібрування в вебкалібраторі. Заводський запис змінює таблицю розділів і може стерти налаштування. Після спарювання відновіть копію через вебкалібратор приймача або напряму через TX.

Під’єднайте кожну плату USB-кабелем і виберіть її COM-порт. За потреби затисніть BOOT, коротко натисніть RESET і відпустіть BOOT. Приклад для передавача:

~~~powershell
python -m esptool --chip esp32s3 --port COM7 write_flash 0x0 axora-esp32-wireless-tx-2.1.3-factory.bin
~~~

Для приймача використайте файл `axora-esp32-wireless-rx-2.1.3-factory.bin`, і його COM-порт.

## Спарювання через вебсторінку приймача

1. Підключіть приймач до ПК, а передавач живіть від зарядного пристрою або павербанка.
2. Через приймач відкрийте **http://axora.local/**. Сторінка **Бездротовий зв’язок** покаже AXORA поблизу. Виберіть пристрій і натисніть **З’єднати**.
3. Звірте вісім спалахів підсвічування AXORA з послідовністю на сторінці. Якщо кольори збігаються, підтвердьте. Після появи **Радіозв’язок активний** можна відкрити **Калібратор**.

Плати самі узгоджують ключ, зберігають пару й надалі з’єднуються автоматично. Пари з попередніх версій зберігаються. Щоб замінити одну з плат, відкрийте **http://axora.local/wireless** і виберіть **Забути пару**. Якщо друга плата була вимкнена або пару налаштовували вручну в попередній версії, очистіть пару й на другій платі через її USB-сторінку. Підключайте до ПК одну плату за раз, бо обидві використовують однакову USB-адресу.

## Робота

- **Передавач напряму.** Підключіть TX кабелем передачі даних до ПК. Він працює як пристрій 3Dconnexion і відкриває власний вебкалібратор за адресою `http://axora.local/`. Приймач для цього режиму не потрібний.
- **Через приймач.** Підключіть RX до ПК, а TX живіть окремо. Вебкалібратор відкривається за адресою `http://axora.local/` через RX. Приймач отримує інтерфейс із TX по ESP-NOW і передає браузеру. Команди, показники та підтвердження йдуть тим самим шляхом. Інтерфейс, калібрування й налаштування зберігаються на TX.
- **Без зв’язку з TX.** Приймач відкриває власну сторінку **Бездротовий зв’язок** для спарювання й локального оновлення RX. Після спарювання виберіть **Калібратор**.
- При розпізнаванні TX по USB прямий USB має пріоритет для рухів і кнопок. Через RX і далі доступний вебкалібратор. Після перемикання відпустіть рукоятку, щоб відновити передачу руху.
- Приймач передає HID для CAD та допоміжні звіти миші й клавіатури по USB. Якщо радіокадри не надходять протягом 150 мс, приймач відпускає кнопки й обнуляє рух.
- Розділ **Оновлення** оновлює плату, підключену до ПК по USB. Для оновлення передавача підключіть його до ПК окремо. Для першої установки використовуйте заводський образ відповідної ролі.

## Підключення передавача

| Підключення | GPIO |
| --- | --- |
| Датчики S1–S8 | 1, 2, 4, 5, 6, 7, 8, 9 |
| Кнопки B1–B3 | 10, 11, 12 |
| Кнопки Pro B4–B9 | 13, 14, 15, 16, 17, 18 |
| DIN першого WS2812B | 21 |
| Нативний USB-C | 19 — D−, 20 — D+ |

Датчики та кнопки підключаються так само, як у дротовій AXORA ESP32. Аналогові входи працюють з рівнями 3,3 В. Зовнішні WS2812B живляться від 5 В і використовують узгодження рівнів для DIN. Для приймача додаткові підключення не потрібні.

## Збірка з ESP-IDF 5.5.2

У каталозі `firmware/esp32`:

~~~bash
idf.py -B build-tx -D IDF_TARGET=esp32s3 -D AXORA_ROLE=tx -D SDKCONFIG=sdkconfig-tx build
idf.py -B build-rx -D IDF_TARGET=esp32s3 -D AXORA_ROLE=rx -D SDKCONFIG=sdkconfig-rx build
~~~

Розкладка для 4 МБ flash має заводський слот і два OTA-слоти по 1 310 720 байтів. Образ передавача займає 1 060 224 байти, приймача — 882 176 байтів. [Документація Espressif ESP-NOW](https://docs.espressif.com/projects/esp-idf/en/v5.5.2/esp32s3/api-reference/network/esp_now.html).
