# AXORA 2.9.1 · AXORA AIR 2.7.0 — Bluetooth

## Оновлення

Оновіть **тільки AXORA / AXORA Pro до 2.9.1** через вебкалібратор,
по USB або через AXORA AIR. Перепрошивати **AIR 2.7.0 не потрібно**:
інтерфейс калібратора знаходиться на AXORA та передається через AIR.
BOOT/RESET не потрібні. Після оновлення перезавантажте сторінку браузера.
Калібрування, налаштування, призначення кнопок і пара зберігаються.

| Прилад | Файл для вебоновлення |
|---|---|
| AXORA / AXORA Pro | [axora-max-tx-2.9.1.bin](axora-max-tx-2.9.1.bin) |
| AXORA AIR — без змін | [axora-esp32-wireless-rx-2.7.0.bin](axora-esp32-wireless-rx-2.7.0.bin) |

[Обидві актуальні прошивки ZIP](AXORA-Bluetooth-2.9.1.zip).
Перед вибором BIN розпакуйте архів. Файли з папки `factory` призначені
для першого запису кабелем, а не для вебоновлювача.

## Зміни

- Звичайний / Експерт — дві кнопки в стилі CAD / Миша / Пауза.
- В експертному режимі селектор моделі AXORA / AXORA Pro знову в шапці.
- Весь пояснювальний текст перевірки миші розташовано зліва.
  Віконце зберігає закріплення при прокручуванні, як тестовий куб CAD.
- Шкала повороту має постійну центральну риску й рухомий маркер у два боки.
- Звичайний клік блимає зеленим, зафіксована кнопка залишається помаранчевою.
  Коротке натискання не губиться між опитуваннями браузера.

Використовуйте оригінальні підписані файли AXORA. Старі непідписані BIN
не приймаються вебоновлювачем. Розмітка пам’яті та робота керування збережені.

Це експериментальний канал: автоматичні перевірки пройдено; фізичні
та тривалі випробування окремо позначаються в звіті.
