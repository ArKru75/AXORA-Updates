# AXORA Bluetooth 2.5.2 · AXORA AIR Bluetooth 2.5.0

У 2.5.2 виправлено незбережені зміни в мобільному калібраторі через Wi-Fi: перегляд переходить по черзі між усіма розділами й профілями; скасування справді видаляє обрану зміну та оновлює лічильник. Інші зміни зберігаються, а скасовані не повертаються після перезавантаження. Центри й налаштування скасовуються без додаткового запиту через Wi-Fi. Після відновлення копії запізніла відповідь більше не стирає нові незбережені центри.

З попередньої 2.5.1 збережено: підказка калібрування для Max називає кнопку **«Меню»**; для AXORA та Pro залишається **кнопка 1**. **Зберегти центри** записує дані лише в пам’ять AXORA. Для файла використовуйте **Калібрування → Резервні копії → Зберегти копію**: центри й повна матриця калібрування зберігаються разом з іншими налаштуваннями.

Також усунено зайве повторне підтвердження нейтралі після короткого невдалого зчитування датчика. Такий цикл дає нульові рухи, наступні коректні виміри дозволяють продовжити роботу. Тривала несправність датчика, справжнє положення поза мертвою зоною та перевірка центру після запуску залишаються захищеними. Збережені центри й матриця автоматично не переписуються.

**Якщо обидва пристрої вже працюють через Bluetooth, оновіть лише AXORA. AIR і збережену пару змінювати не потрібно.**

Окрема гілка для **Bluetooth-з’єднання між AXORA та AXORA AIR**. ESP-NOW у цих прошивках не використовується.
Підтримуються AXORA, AXORA Pro та AXORA Max із поточною розпіновкою. Пряме USB-підключення збережене.

| Пристрій | BIN для «Оновити з файлу» |
|---|---|
| AXORA / Pro / Max | [axora-max-tx-2.5.2.bin](axora-max-tx-2.5.2.bin) |
| AXORA AIR | [axora-esp32-wireless-rx-2.5.0.bin](axora-esp32-wireless-rx-2.5.0.bin) |

[Обидві актуальні прошивки одним архівом](AXORA-Bluetooth-2.5.2.zip). Архів спочатку розпакуйте.

## Як перейти з ESP-NOW на Bluetooth

1. Завантажте обидва BIN-файли на комп’ютер.
2. Підключіть **AXORA AIR безпосередньо через USB**. Відкрийте `http://axora.local/wireless` → **Оновлення з файлу** й виберіть BIN для AIR. Дочекайтеся завершення.
3. Від’єднайте AIR та підключіть **AXORA безпосередньо через USB**. Відкрийте `http://axora.local` → **Оновлення → Оновити з файлу**, виберіть BIN для AXORA. Дочекайтеся завершення.
4. Підключіть AIR до комп’ютера, а AXORA — до зарядженого павербанка або іншого стабільного джерела живлення без USB-з’єднання з комп’ютером.
5. Відкрийте `http://axora.local/wireless`, виберіть AXORA, натисніть **З’єднати** та підтвердьте однаковий порядок кольорів.

**BOOT і RESET для цього переходу не потрібні.** Розмітка пам’яті й назви пристроїв у файлах оновлення збережені.
Модель, калібрування, налаштування та призначення кнопок залишаються.

Bluetooth-пару потрібно створити заново. Вона зберігається окремо від старої пари ESP-NOW.
Пристрої з різними типами прошивок між собою не з’єднаються: оновіть обидва.
Спарювання відбувається у вебсторінці AIR; додавати пристрій у Bluetooth-меню Windows або macOS не потрібно.

Після спарювання AIR передає рухи й кнопки комп’ютеру через USB, а калібратор читає з AXORA через Bluetooth.
Подальше оновлення AXORA через AIR також передбачене. Wi-Fi для телефона вмикається після 10 секунд без USB та зв’язку з AIR.

## Статус перевірки

Це експериментальні прошивки для перевірки на двох реальних пристроях.
AXORA 2.5.2 зібрана офіційним ESP-IDF 5.5.2 на self-hosted runner. [Повна перевірка GitHub Actions](https://github.com/ArKru75/AXORA/actions/runs/45836343700) пройшла: нативні тести, п’ять браузерних наборів та обидві прошивки. Новий мобільний тест відтворює Wi-Fi і USB, кілька профілів та розділів, скасування, повторний перегляд і перезавантаження на ширинах 320–640 пікселів. Формат BIN, запас пам’яті та незмінність таблиці розділів перевірено. Опублікована AIR 2.5.0 не змінена. Новий інтерфейс на фізичний телефон у цій перевірці не встановлювався.
Виправлення повторного очікування нейтралі ще потрібно перевірити на ваших пристроях; якщо біле миготіння повториться, важливий точний напис у калібраторі.
