# AXORA 2.9.7 · AXORA AIR 2.7.1 — Bluetooth

Оновіть **лише AXORA / AXORA Pro до 2.9.7** у вебкалібраторі через USB
або AXORA AIR. **AIR 2.7.1 не потребує оновлення**.
Калібрування, налаштування, кнопки та пара зберігаються.
Після встановлення перезавантажте сторінку. BOOT/RESET не потрібні.

| Прилад | BIN для вебоновлення |
|---|---|
| AXORA / AXORA Pro | [axora-max-tx-2.9.7.bin](axora-max-tx-2.9.7.bin) |
| AXORA AIR — без змін | [axora-esp32-wireless-rx-2.7.1.bin](axora-esp32-wireless-rx-2.7.1.bin) |

[Обидві актуальні прошивки ZIP](AXORA-Bluetooth-2.9.7.zip).
Розпакуйте перед вибором BIN. Файли з папки `factory` — для першого запису кабелем.

## Зміни

- У «Центрах датчиків» детальне пояснення невдалої перевірки: номер датчика,
  фактичні значення, допустима межа та рекомендація для кожної причини.
- Розрізняються зміщений центр, нестабільні показання, стрибки, поступове
  зміщення, досягнення меж датчика та натиснута під час перевірки кнопка.
- Результати невдалої перевірки зберігаються окремо від поточних показань.
  Автоматична повторна перевірка не стирає причину, а її читання не затримує
  відновлення роботи. Дані різних перевірок не змішуються.
- Пояснення зникає після успішної перевірки. Незбережені зміни не втрачаються.
- Українська й англійська, комп’ютер і телефон. Пороги перевірки не змінювалися.

[Інструкція українською (PDF)](AXORA-User-Guide-UK.pdf) · [English (PDF)](AXORA-User-Guide-EN.pdf).

Використовуйте оригінальні підписані BIN AXORA. Розмітка пам’яті та режими
керування збережені. Це експериментальний канал: автоматичні перевірки
пройдено; фізичне випробування пристроїв у цьому завданні не виконувалося.
