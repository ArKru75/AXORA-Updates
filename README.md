# AXORA 2.9.2 · AXORA AIR 2.7.0 — Bluetooth

Інструкції до поточних AXORA (4 кнопки) та AXORA Pro (15 кнопок), по 6 сторінок:
[Українською (PDF)](AXORA-User-Guide-UK.pdf) · [English (PDF)](AXORA-User-Guide-EN.pdf).
Підключення, калібрування, CAD, миша, AIR, телефон, оновлення та допомога.

Оновіть **лише AXORA / AXORA Pro до 2.9.2** через вебкалібратор,
по USB або через AXORA AIR. **AIR 2.7.0 не потребує оновлення**:
калібратор зберігається на AXORA і передається через AIR.
Після встановлення перезавантажте сторінку браузера.
Калібрування, параметри, кнопки та пара зберігаються. BOOT/RESET не потрібні.

| Прилад | BIN для вебоновлення |
|---|---|
| AXORA / AXORA Pro | [axora-max-tx-2.9.2.bin](axora-max-tx-2.9.2.bin) |
| AXORA AIR — без змін | [axora-esp32-wireless-rx-2.7.0.bin](axora-esp32-wireless-rx-2.7.0.bin) |

[Обидві актуальні прошивки ZIP](AXORA-Bluetooth-2.9.2.zip).
Перед вибором BIN розпакуйте архів. Файли з папки `factory` призначені
для першого запису кабелем, а не для вебоновлення.

## Зміни інтерфейсу

- Верхній рядок: лого й модель зліва; інструкція, прапорці мови,
  підключення та версія справа. Вибір моделі доступний в експертному режимі.
- Нижній рядок: CAD / Миша / Пауза зліва; Звичайний / Експерт справа.
- Керування приладом має знайомі кольори; рівень інтерфейсу — нейтральний.
- На телефоні перемикачі займають окремі рядки на всю ширину.
  Інструкція доступна в Допомозі за наявності інтернету.

Використовуйте оригінальні підписані файли AXORA. Старі непідписані BIN
не приймаються вебоновлювачем. Розмітка пам’яті та керування збережені.
Це експериментальний канал: автоматичні перевірки пройдено;
фізичні та тривалі випробування окремо позначаються у звіті.
