# AXORA Bluetooth 2.8.1 · AXORA AIR Bluetooth 2.6.2

Виправлено фіксацію при звичайному повороті та проблему відпускання кнопок.

## Установлення

Оновіть **AXORA / AXORA Pro до 2.8.1** через вебкалібратор: режим
**Експерт → Оновлення → Перевірити оновлення** або **Оновити з файлу**.
Установлення доступне через USB або Bluetooth AXORA AIR, без BOOT/RESET.
Після встановлення перезавантажте сторінку браузера.
**AIR 2.6.2 повторно оновлювати не потрібно.**

| Пристрій | BIN для вебоновлення |
|---|---|
| AXORA / AXORA Pro | [axora-max-tx-2.8.1.bin](axora-max-tx-2.8.1.bin) |
| AXORA AIR — без змін | [axora-esp32-wireless-rx-2.6.2.bin](axora-esp32-wireless-rx-2.6.2.bin) |

[Обидві актуальні прошивки ZIP](AXORA-Bluetooth-2.8.1.zip). Перед вибором BIN розпакуйте архів.

## Кліки й фіксація

* Легко поверніть ручку навколо вертикалі ліворуч/праворуч і поверніть
  у центр — спрацює лівий/правий клік.
* Утримайте сильний поворот коротку мить — відповідна кнопка зафіксується.
  Нахиляйте ручку для перетягування.
* Щоб відпустити, повторно поверніть у той самий бік. Цей жест звільняє
  кнопку навіть тоді, коли вийшов сильнішим. Повторного затискання тим самим
  жестом немає. Невеликий залишковий поворот після повернення допускається.
* Натискання вниз перемикає фіксацію середньої кнопки — натискання на колесо.
  Нахили керують курсором, зміщення паралельно основі — прокручуванням.
* Усі фізичні кнопки виконують призначення 3DxWare. Довге утримання фізичної
  2 на AXORA / верхньої 4 на Pro з відпусканням перемикає CAD / Миша.

## Зусилля фіксації

Відкрийте **Налаштування миші → Зусилля фіксації**. Початково **125%**,
діапазон **70–250%**. Якщо легкий поворот фіксує кнопку — збільште значення;
якщо сильний не фіксує — зменште. Натисніть **Зберегти**.

Поріг має бути перевищений близько 0,18 секунди. Поворот нижче порога
залишається кліком, навіть якщо утримувати його довше. Короткий сильний рух
також дає клік після повернення. Параметр входить у чернетки й резервні копії;
є скасування змін, перевірка запису та відновлення зі старих копій.

У **Напрямках рухів** додано **Поворот навколо вертикалі → Навпаки** із
зображенням руху. Він міняє місцями ліві й праві кліки, фіксацію та
відпускання. Натискання вниз залишається середньою кнопкою. Натисніть
**Зберегти**, щоб застосувати інверсію. Підказка кліків показує збережений
напрямок; інверсія також входить у резервну копію.

У панелі перевірки видно зафіксовані кнопки. **Пауза** відпускає всі кнопки.
Пороги перевірки центрів датчиків не змінені. Калібрування, призначення,
швидкості миші, інверсії, яскравість і Bluetooth-пара зберігаються.

Розмітка OTA та імена проєктів збережені; назва `axora-max-tx` потрібна
для сумісності попереднього вебоновлювача. Використано резервний байт
наявного запису параметрів миші. Повернення на 2.8.0 після збереження нового
зусилля скине параметри миші на початкові тієї версії; калібрування й інші
окремі налаштування від цього не залежать.

## Перевірки

[Повні тести й обидві збірки](https://github.com/ArKru75/AXORA/actions/runs/46013315271): C++ з UBSan, Bluetooth/OTA та шість
браузерних наборів. Регресія відтворила помилку 2.8.0 із залишковим
поворотом 14%. Виправлення перевірено для обох сторін, слабких/сильних і
коротких/довгих жестів, повторного відпускання без затискання, утримання й
комбінованих кнопок, запису зусилля, меж і помилок запису, чернеток,
старих копій, обох мов та мобільного вигляду. Розмір, контрольні суми,
оригінальні OTA-розділи та відповідність заводського й OTA-образів перевірені.
Фізичний пристрій не прошивався; зусилля можна підібрати під його механіку.
