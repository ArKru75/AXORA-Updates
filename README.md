# AXORA Bluetooth 2.8.0 · AXORA AIR Bluetooth 2.6.2

## Установлення

Оновіть **AXORA / AXORA Pro до 2.8.0** через вебкалібратор: режим
**Експерт → Оновлення → Перевірити оновлення** або **Оновити з файлу**.
Доступне встановлення через USB або Bluetooth AXORA AIR, без BOOT/RESET.
Після встановлення перезавантажте сторінку браузера.

**AXORA AIR залишається 2.6.2.** Якщо ця версія вже встановлена,
повторно оновлювати AIR не потрібно. Для старішої AIR спочатку встановіть 2.6.2.

| Пристрій | BIN для вебоновлення |
|---|---|
| AXORA / AXORA Pro | [axora-max-tx-2.8.0.bin](axora-max-tx-2.8.0.bin) |
| AXORA AIR — без змін | [axora-esp32-wireless-rx-2.6.2.bin](axora-esp32-wireless-rx-2.6.2.bin) |

[Обидві актуальні прошивки ZIP](AXORA-Bluetooth-2.8.0.zip). Перед вибором BIN розпакуйте архів.

## Керування в режимі миші

| Рух ручки | Дія |
|---|---|
| Нахил ліворуч/праворуч, уперед/назад | Курсор |
| Зміщення паралельно основі | Прокручування вгору/вниз або вбік |
| Легкий поворот навколо вертикалі ліворуч, потім у центр | Лівий клік |
| Легкий поворот праворуч, потім у центр | Правий клік |
| Сильний поворот ліворуч або праворуч | Зафіксувати відповідну кнопку |
| Повторний легкий поворот у той самий бік, потім у центр | Відпустити зафіксовану кнопку |
| Натискання ручки вниз | Зафіксувати середню кнопку — натискання на колесо |
| Повторне натискання вниз | Відпустити середню кнопку |

Для перетягування зробіть сильний поворот ліворуч, поверніть ручку в центр,
потім нахиляйте її. Щоб завершити перетягування, легко поверніть ліворуч
і поверніть у центр. Лівий, правий та середній стани незалежні.

Клік після легкого повороту спрацьовує при поверненні в центр: сильний
поворот завдяки цьому не створює попереднього зайвого кліку. Сильний поворот
уже зафіксованої кнопки залишає її зафіксованою. Відпускання — легким жестом.
Натискання вниз утримує **середню кнопку**, а нахили продовжують рухати курсор.

## Фізичні кнопки та калібратор

Усі фізичні кнопки в режимі миші виконують збережені призначення **3DxWare**.
AXORA **2** / верхня **4** на AXORA Pro зберігає довге перемикання CAD / Миша
після утримання приблизно секунду й відпускання. Коротке натискання передає
її призначення 3DxWare.

У тестовій панелі видно, які кнопки зафіксовані. Є пояснення жестів
українською й англійською. Пауза у шапці відпускає всі кнопки; вихід із
режиму миші, початок калібрування, тест куба, збереження параметрів миші,
помилка датчиків та перезапуск також скидають фіксацію.

Розпізнавання жестів приглушує супутні випадкові рухи курсора. Пороги й
часовий захист відсікають короткі стрибки; утримання ручки внизу перемикає
середню кнопку один раз до її повернення в центр. Перший варіант порогів
потребує практичної перевірки на вашому пристрої.

Налаштування CAD, калібрування, центри, призначення кнопок, параметри миші,
яскравість і Bluetooth-пара зберігаються. Розмітка OTA, імена проєктів та
формат налаштувань миші не змінені. Назву `axora-max-tx` збережено для
сумісності попереднього вебоновлювача. Звичайна AXORA має 4 кнопки,
AXORA Pro — 15; розпіновка й сім світлодіодів лишилися попередніми.

## Перевірки

[Повні тести й обидві збірки](https://github.com/ArKru75/AXORA/actions/runs/46009772945): C++ з UBSan, Bluetooth/OTA та шість
браузерних наборів. Окремо перевірено ліві/праві кліки й фіксацію, середню
кнопку, повторні жести, одночасні стани, шум, перетягування, приглушення
супутніх рухів, скидання при зміні режиму та невалідних даних, реальні
HID-звіти, усі 4/15 фізичних кнопок, індикацію у вебінтерфейсі, обидві мови
та вузькі екрани. Розмір, контрольні суми, оригінальні OTA-розділи,
сумісність та відповідність заводського й OTA-образів перевірені.
Фізичні пристрої не прошивалися.
