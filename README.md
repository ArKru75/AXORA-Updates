# AXORA Bluetooth 2.8.2 · AXORA AIR Bluetooth 2.6.2

## Установлення

Оновіть **AXORA / AXORA Pro до 2.8.2** через вебкалібратор: режим
**Експерт → Оновлення → Перевірити оновлення** або **Оновити з файлу**.
Доступне встановлення через USB або Bluetooth AXORA AIR, без BOOT/RESET.
Після встановлення перезавантажте сторінку браузера.
**AIR 2.6.2 повторно оновлювати не потрібно.**

| Пристрій | BIN для вебоновлення |
|---|---|
| AXORA / AXORA Pro | [axora-max-tx-2.8.2.bin](axora-max-tx-2.8.2.bin) |
| AXORA AIR — без змін | [axora-esp32-wireless-rx-2.6.2.bin](axora-esp32-wireless-rx-2.6.2.bin) |

[Обидві актуальні прошивки ZIP](AXORA-Bluetooth-2.8.2.zip). Перед вибором BIN розпакуйте архів.

## Керування мишею

| Рух ручки | Дія за початкового напрямку |
|---|---|
| Нахил | Переміщення курсора |
| Зміщення паралельно основі | Прокручування |
| Поворот приблизно до половини ходу за годинниковою, потім у центр | Лівий клік |
| Поворот приблизно до половини ходу проти годинникової, потім у центр | Правий клік |
| Максимальний поворот із утриманням близько 0,35 с | Фіксація відповідної кнопки |
| Повторний поворот до половини ходу в той самий бік | Відпускання зафіксованої кнопки |
| Глибоке натискання вниз із утриманням близько 0,2 с | Фіксація середньої кнопки — натискання на колесо |
| Повторне окреме глибоке натискання вниз | Відпускання середньої кнопки |

Невеликі повороти не створюють кліків. Утримання повороту на половині ходу
залишається кліком. Короткий вихід на максимум також дає клік після
повернення; фіксація потребує утримання. Після фіксації можна повернути
ручку в центр і нахиляти її для перетягування. **Пауза** відпускає всі кнопки.

У **Налаштуваннях миші → Напрямки рухів → Поворот навколо вертикалі →
Навпаки** можна поміняти ліву та праву дії місцями. Стан перемикача
збережений із попередньої версії; змінився базовий напрямок. Підказки у
калібраторі показують збережений варіант. Натисніть **Зберегти** для зміни.

## Захист середньої кнопки

Натискайте ручку вниз окремим глибоким рухом. Неглибокого або короткого
натискання недостатньо. Рух униз має переважати нахили та зміщення.
Під час повороту супутнє натискання не створює середню кнопку. Воно також
не спрацьовує із запізненням після зупинки повороту: спочатку відпустіть
ручку, потім натисніть вниз окремим рухом. Утримання ручки внизу не
перемикає кнопку багаторазово. У тестовій панелі видно зафіксовані кнопки.

## Параметри й сумісність

Початкове **Зусилля фіксації** — **100%** каліброваного повороту, замість
попереднього порога. Старий поріг під час переходу на цю версію скидається
на нові 100%. Повзунок 70–250% залишено для підстроювання під механіку;
після **Зберегти** нове власне значення зберігається. Швидкості, зони
спокою, інверсії, калібрування, центри, призначення кнопок, яскравість і
Bluetooth-пара збережені. Явне відновлення старої копії із власним зусиллям
застосовує значення з цієї копії.

Усі фізичні кнопки працюють через 3DxWare. Довге утримання фізичної 2
на AXORA / верхньої 4 на Pro з відпусканням перемикає CAD / Миша.
Формат радіо HID, STATE, MOUSECFG, розмітка OTA та імена проєктів збережені.
Старий запис параметрів миші приймається; новий має ту саму довжину 16 байт
та нову версію запису. Назва `axora-max-tx` потрібна для сумісності оновлювача.

## Перевірки

[Повні тести й обидві збірки](https://github.com/ArKru75/AXORA/actions/runs/46017784233): C++ з UBSan, Bluetooth/OTA та шість
браузерних наборів. Регресія відтворила помилкове натискання середньої
кнопки під час повороту. Перевірені глибина, час, переважання вертикального
руху, переривання натискання поворотом, відсутність відкладеного спрацювання,
повторне натискання після повернення, HID-звіти, обидва напрямки й інверсія,
поворот нижче половини, рівно половина, межа 350 мс та коливання на максимумі,
старі записи й резервні копії, українська/англійська та мобільний вигляд.
Розмір, контрольні суми, оригінальні OTA-розділи, сумісність і відповідність
заводського й OTA-образів перевірені. Фізичний пристрій не прошивався.
