# AXORA 2.3.3 — збереження та вибір моделі

Прошивка для AXORA, AXORA Pro й AXORA Max. AXORA AIR 2.1.27 не потребує оновлення: калібратор зберігається на AXORA та відкривається через приймач.

## Центри датчиків

Спочатку натисніть **Зчитати центри**. Після зміни значень з’являється **Є незбережені зміни**, кнопка зчитування перетворюється на **Скасувати зміни**. Скасування повертає попередні значення без запису в AXORA. **Зберегти центри** доступна лише для правильних змінених значень. Під час запису поля заблоковані. Перед записом завантажується резервна копія, після нього дані зчитуються для підтвердження. Невдала операція залишає чернетку.

## Підсвічування

Повзунок одразу показує яскравість на пристрої, але постійний запис виконується лише кнопкою **Зберегти яскравість**. Статус порівнює вибране значення зі збереженим у AXORA. **Скасувати зміни** повертає збережену яскравість без нового постійного запису. Зайві збереження заблоковані. Після помилки чернетка лишається, після підтвердження запису статус стає **Збережено**. Повторне зчитування підключення та зміна моделі не стирають чернетку яскравості.

## Модель пристрою

Вибір **Модель** вже зберігається на AXORA окремо від браузера: AXORA, Pro та Max мають різні позначки навіть при однаковій кількості лампочок. Зміна моделі записується одразу; кнопка збереження яскравості для цього не потрібна. При запуску прошивка відновлює модель і відповідне підключення кнопок. Калібратор при кожному новому підключенні читає команду MODEL і підлаштовує селектор, зображення калібрування, схему кнопок і кількість лампочок. До отримання відповіді показано **Визначення моделі…**, а селектор заблокований. Модель браузера за замовчуванням не записується в пристрій.

## Перевірки та сумісність

Браузерні перевірки охоплюють обидві мови, чернетки й скасування, явне збереження, помилки запису, підтвердження даних, блокування під час операції, повторне зчитування та екрани 320/390 px. Перевірено автоматичне налаштування для кожної з трьох моделей при підключенні через USB і AIR без команд зміни моделі. Тест прошивки відновлює кожну модель новим об’єктом сховища після запису для імітації запуску.

Калібрування, профілі, кнопки, розпіновка, радіопара, USB та схема пам’яті не змінюються. Повторне калібрування й спарювання не потрібні. Установлення та тривалий тест на фізичних пристроях виконуються окремо.
